# YAHILI - Yet Another Haskell-Implemented Lox Interpreter

Creating an interpreter for the Lox programming language, following along with the book Crafting Interpreters. https://craftinginterpreters.com/

Doing so in Haskell, as the name indicates. Since I'm still new to Haskell, I consult Gemini from time to time when I'm having trouble figuring out how to accomplish something in the language.

When I have Gemini or another LLM examine my code directly via the Antigravity IDE and I use some part of the output, I mark the commit with AGY. I aim to keep this at a minimum, because half the fun is learning how to do this myself!
